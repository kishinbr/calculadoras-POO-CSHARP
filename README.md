# 🧮 Calculadora Científica em C#

Projeto desenvolvido em **C#** com o objetivo de praticar conceitos de **Programação Orientada a Objetos (POO)**.

## 📚 Conceitos praticados

* Classes e objetos
* Construtores
* Encapsulamento
* Herança
* Métodos
* Modificadores de acesso (`private` e `public`)
* Uso de `base`
* Operações matemáticas

## ⚙️ Funcionalidades

### Calculadora Base

* Soma
* Subtração
* Multiplicação
* Divisão

### Calculadora Científica

* Potência
* Raiz quadrada
* Logaritmo
* Seno
* Cosseno
* Tangente

## 🛠️ Tecnologias

* C#
* .NET

## 🎯 Objetivo

Projeto criado como parte dos meus estudos em **C# e Programação Orientada a Objetos**, buscando evoluir gradualmente meus conhecimentos através de projetos práticos.
